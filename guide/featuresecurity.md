# FeatureSecurity
Se usa para validar las acreditaciones de los usuarios, logeados en la aplicacion validando sus credemnciasl
y permisos. Se usa para aplicaciones clientes FrontEnd, donde se valida el acceso a las Paginas, y otros Metodos

como Page,Services entre otros.

```java
@PageDeclareRoles 
@PageRolesAllowed
@MenuDeclareRoles 
@MenuRolesAllowed
```
